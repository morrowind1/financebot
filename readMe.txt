Этот бот предназначен для контроля личного бюджета,
отслеживания ежедневных лимитов и накопления средств на цели.

СИСТЕМНЫЕ ТРЕБОВАНИЯ

Python: версия 3.10 или выше.

База данных: SQLite (уже встроена в Python).

Библиотеки: aiogram, aiosqlite, matplotlib, pandas.



ПОДРОБНАЯ УСТАНОВКА И ЗАПУСК

ШАГ 1: ПОДГОТОВКА ОКРУЖЕНИЯ (VENV)

Рекомендуется использовать виртуальное окружение, чтобы
библиотеки бота не конфликтовали с другими проектами.

Создание окружения:
Откройте терминал в папке с ботом и введите:
python -m venv venv

Активация окружения:

Windows:
venv\Scripts\activate

macOS / Linux:
source venv/bin/activate

После активации в начале строки появится надпись (venv).

ШАГ 2: УСТАНОВКА БИБЛИОТЕК

Когда окружение активно (есть надпись venv), введите:
pip install --upgrade pip
pip install -r requirements.txt

ШАГ 3: НАСТРОЙКА ТОКЕНА

Найдите в Telegram бота @BotFather.

Напишите ему /newbot и получите API Token.

Откройте файл main.py (или config.py) и вставьте
токен в переменную TOKEN = "ВАШ_ТОКЕН".

ШАГ 4: ЗАПУСК БОТА

Введите в терминале:
python main.py

ЧТО ДЕЛАЮТ КНОПКИ (ГЛАВНОЕ МЕНЮ)

[ 💰 Бюджет ]
Позволяет установить общую сумму денег на текущий месяц.
Бот сам высчитает лимит трат на каждый день.

[ 🗓 День ЗП ]
Установка даты зарплаты. Бот спросит число и месяц.
Если выбрать месяц "0", дата будет повторяться каждый месяц.

[ ➕ Добавить трату ]
Вводите сумму и выбираете категорию. Бот сразу вычтет
деньги из бюджета и обновит ваш дневной лимит.

[ 🎁 Копилка ]
Меню накоплений. Здесь можно создавать цели (например,
на машину) и переводить туда деньги.
Автокопилка (включается в настройках) сама будет
округлять ваши траты и кидать "сдачу" в копилку.

[ 📊 История ]
Показывает список ваших последних 15 трат: что, когда
и сколько вы купили.

[ 🔄 Обновить лимит ]
Быстрая сводка: баланс, сколько дней до ЗП и сколько
можно потратить сегодня без вреда для кошелька.

[ ⚙️ Настройки ]
Здесь можно включить Автокопилку или полностью ОЧИСТИТЬ
базу данных (удалить все траты и цели).
