привет! для запуска бота нужно всего 4 шага.
всё просто, следуй по порядку.


шаг 1 — создай виртуальное окружение
──────────────────────────────────────
виртуальное окружение — это изолированная папка
с библиотеками специально для этого проекта.

создание:
    python -m venv venv

активация (windows):
    venv\Scripts\activate

активация (linux / macos):
    source venv/bin/activate

после активации в начале строки появится (venv) —
это значит всё ок.


шаг 2 — установи зависимости
──────────────────────────────
убедись что (venv) есть в начале строки и впиши:

    pip install -r requirements.txt

дождись установки — может занять пару минут.


шаг 3 — получи токен бота
──────────────────────────
токен — это уникальный ключ твоего бота,
его нужно получить через официальный telegram-бот.

1. открой telegram и найди @botfather
2. напиши команду /newbot
3. придумай имя и юзернейм для бота
4. botfather пришлёт токен — выгляди вот так:
   123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

!! важно: при создании бота убедись что
стоит галочка разрешения на сообщения.

5. скопируй токен и вставь его в файл .env вот так:
   BOT_TOKEN=123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx


шаг 4 — запусти бота
──────────────────────
убедись что (venv) есть в начале строки и впиши:

запуск (windows):
    python main.py

запуск (linux / macos):
    python3 main.py

вуаля! бот работает 🎉


================================
  если что-то пошло не так
================================

— нет (venv) в начале строки
  повтори активацию из шага 1

— ошибка "module not found"
  убедись что зависимости установлены (шаг 2)
  и что виртуальное окружение активно

— бот не отвечает
  проверь токен в файле .env —
  он должен быть без пробелов и кавычек
